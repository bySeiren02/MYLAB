# 자기 개발 앱

자기 개발을 위한 종합 관리 앱입니다.

## 기능

### 메인 페이지
- 날짜별 일기 작성
- 기분 선택 (10가지 아이콘)
- 오늘의 질문 (100개 질문 순환)
- 10개 메뉴 접근

### 메뉴 기능

1. **러닝 스톱워치**
   - 인터벌 러닝 시간 측정
   - 세트별 랩 기록

2. **데일리 투두리스트**
   - 일일 할 일 관리
   - 체크리스트
   - 드래그 앤 드롭으로 순서 변경

3. **캘린더**
   - 6개 카테고리로 일정 관리
   - 일정 추가/수정/삭제

4. **월별 목표**
   - 월별 목표 설정 및 추적
   - 진행률 표시

5. **연간 목표**
   - 연간 목표 설정 및 추적
   - 진행률 표시

6. **다이어트**
   - 일일 몸무게 기록
   - 식단 등록 (아침/점심/저녁/간식)
   - 운동 등록
   - 칼로리 계산

7. **독서 기록**
   - 읽은 책 기록
   - 독후감 작성
   - 평점 및 상태 관리

8. **스터디 플랜**
   - 공부 계획 체크리스트
   - 진행률 추적

9. **영양제**
   - 일일 영양제 복용 체크리스트
   - 드래그 앤 드롭으로 순서 변경

10. **요일별 피부 루틴**
    - 요일별 피부 관리 루틴
    - 체크리스트
    - 드래그 앤 드롭으로 순서 변경

## 설치 및 실행

```bash
# 패키지 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build
```
